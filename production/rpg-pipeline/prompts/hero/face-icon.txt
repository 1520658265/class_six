# 头像 Prompt 模板
# 使用方式：从立绘裁切上半身后，用 img2img 精修为正方形头像

# === img2img 正向 Prompt ===
{base-style.txt 内容},
close-up portrait, head and shoulders, centered face,
{角色描述：发色/发型/肤色/五官},
pixel art portrait icon, rpg character icon, HD-2D style,
simple background, (square composition:1.2),
<lora:pixel_art_hd:0.9> <lora:char_{角色名}:0.8>

# 尺寸: 256x256
