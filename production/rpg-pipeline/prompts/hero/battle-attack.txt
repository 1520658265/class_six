# 战斗图 Prompt 模板 — 攻击 attack（6 帧循环）
# 使用方式：每帧单独生成，与 base-style.txt 拼接

# === 正向 Prompt（单帧） ===
{base-style.txt 内容},
solo, 1boy/1girl, {角色描述},
{服装描述 / "base layer" 用于基础层},
battle stance, sword slash, attacking,
side view, facing right, rpg battle scene perspective,
{帧描述},
single character sprite, centered in frame, full body,
(transparent background:1.3), (single frame:1.2),
<lora:pixel_art_hd:0.9> <lora:char_{角色名}:0.8>

# === 帧描述变量（6 帧攻击循环） ===
# frame1: wind up, pulling weapon back
# frame2: arm raised, ready to strike
# frame3: swing forward, blade in motion
# frame4: impact moment, weapon connecting
# frame5: follow through, blade past target
# frame6: recovery stance, returning to ready

# === Liblib 参数 ===
# 底模: SDXL 1.0 / Pony V6
# 尺寸: 768x768（生成后裁切缩放至 256x256）
# 采样器: DPM++ 2M Karras
# 步数: 30
# CFG: 6-7
# Seed: {角色固定 seed}
# ControlNet: OpenPose, 权重 0.8
#   - 模板图: controlnet/battle-attack-{帧号}.png

# === 图层说明 ===
# 基础层: 服装改为 "base layer, minimal clothing"
# 武器层: prompt 改为 "{武器描述}, (only weapon visible:1.3), (no body:1.2)"
