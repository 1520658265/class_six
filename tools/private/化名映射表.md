## 五、命名规则约定

- 资产文件名（PNG/TSCN）：化名拼音（无声调）+ 全小写 + 下划线，例：`char_baoxianjin_*`
- 对白脚本中说话人字段：使用化名（中文）
- 任何 push 到 git 的文档：仅出现化名，不出现原型真名
- 本文件（化名映射表）通过 `.gitignore` 排除，仅本机保留
