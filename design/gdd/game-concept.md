# 《元生的六年级》— Game Concept

> **Note**: 本文档基于既有故事线、demo 切片代码与 NPC/属性/事件设计反向凝练。
> 视角范式以代码为准为 **俯视 4 方向**；早期"横版格斗 RPG"方向已归档于 [docs/archive/横版格斗-archive/](../../docs/archive/横版格斗-archive/README.md)（2026-06-01 Superseded）。
> Demo 切片范围：序章 + 第一章。后续章节范围列在「范围与优先级」一节。

## 一、Overview

《元生的六年级》是一款 **2D 俯视 4 方向 RPG**，叙事驱动，写实题材。透过 11 岁山区男孩元生的眼睛，呈现 2008 年 9 月 — 2009 年 7 月这一年中国最后一代"前互联网童年"的生活切片。游戏以丁埠小学（卡过渡届的最后一届六年级）为主舞台，用俯视场景切换关卡 + 轻量近战格斗承载冲突，用属性 / 好感度 / 选择分支承载成长，用时代切片标记承载主题。元生不是英雄，是镜头。

## 二、Player Fantasy

让玩家"代入到那种说不出口的感觉"——胆小、脸红、攥着 5 毛钱不敢进小卖部、被人欺负只敢低头、第一次摸键盘手心出汗、第一次被同龄人挡了一下后眼眶发热。

游戏不许诺英雄之旅。它许诺的是：
- **被看见**：当你蹲下、不说话、转身离开的时候，游戏知道你在做什么
- **被允许**：选 A（不吭声）也是合法选择，不是低分路线，是真实的童年
- **被记住**：那些"心结 +1""钱包羞耻度 +2"会以某种方式回到你身上
- **被托住**：在最难的时候，姐姐的一封信、鲍师母多塞的一颗糖、曾建明递过来的橡皮，足以让你撑过去

## 三、核心玩法定位

| 维度 | 定位 |
|---|---|
| 移动视角 | 2D 俯视 4 方向（上/下/左/右；场景切换式探索，无世界地图） |
| 战斗风格 | 俯视近战为主（拳脚 / 推搡 / 书包砸 / 扫帚 / 环境利用），无器械，胆量解锁进阶 |
| RPG 层 | 4 项显性属性 + 3 项隐性变量 + NPC 好感度 + 时代切片标记 |
| 叙事层 | 章节推进，事件流程图驱动，cutscene + 对话分支，可回忆插叙 |
| 基调 | 写实山区童年；不超现实，不魔法，不英雄主义 |
| 战斗承载量 | 主线 7 个战斗节点（序章与终章无战斗，第四章为家庭休整章无战斗） |

### 战斗的"合理性框架"

元生是 11 岁小学生，战斗必须贴合现实：
- 只能拳脚、推搡、摔跤、书包抡
- 环境利用：课桌椅、扫帚、黑板擦、饭盒
- **俯视近战范式**：4 方向移动 + 4 方向出招（不依赖跳跃 / 重力），战斗发生在房间/走廊式有界场景内
- **情绪系统驱动**：胆量属性决定能否发动某些攻击；胆量低 → 只能防御 / 逃跑；胆量高 → 解锁"硬刚""反推"
- **战斗不是主旋律**：多数冲突可以用逃跑 / 对话 / 告状解决，选战斗是高属性的奖励路线

## 四、双层结构

- **A 层 · 时代切片**：每章绑定一个 2008–2009 年的标志性事件——开学、神舟七号、三鹿、火力少年王、留守冬夜、第一次摸电脑（4399 / QQ）、春节冰灾余响、汶川一周年、奥运回响、撤点并校。切片即气氛、即冲突、即主题。
- **B 层 · 贯穿 BOSS 线**：曹正东作为"留守 + 隔代抚养 + 山村失序"现象的人格代表，承载横版战斗的主要承载量；从开学到毕业一路递进，第二章 2.2.5 卫生院门口预埋"看见过曹正东的另一面"，第八章 BOSS 战 D 选项的解锁条件读取该标记。

## 五、主要系统（demo 范围）

- **属性系统（显性 4）**：学习 / 胆量 / 口才 / 体力（初值 1–3，0–10）
- **隐性变量（3）**：心结（0–20）、卡过渡届心理度（0–10）、钱包羞耻度（0–20）
- **NPC 好感度**：12 位 demo NPC（鲍先进 / 鲍师母 / 王炎 / 曾建明 / 曹正东 / 胡晓东 / 张磊 / 李静 / 父亲 / 母亲 / 姐姐 / 门卫大爷）
- **时代切片标记**：每章触发该年标志性事件时累积，集齐后第七章高潮强度提升、终章独白解锁
- **对白与事件**：自家 JSON 格式（`data/dialogue/*.json`），cutscene runner + scene router 驱动
- **存档**：宿舍存档点 + 二班靠窗第三排 + 曾建明家（第三章解锁）

## 七、目标受众

叙事 2D / 独立游戏全市场，能欣赏《空洞骑士》《蔚蓝》《Night in the Woods》《Oxenfree》这类作品的玩家。文化背景上 70-90 后中国小镇 / 农村背景成长的玩家会获得额外代际共鸣，但游戏机制与情感张力不依赖该共鸣即可成立。

## 八、Demo 范围与优先级

| **第一章 · 蒸饭盒里的秋天** | 时代切片：神舟七号 + 三鹿 | 1（曹正东第一次抢钱） | demo 必交付 |

Demo 场景：home / mountain_road_autumn / school_gate / corridor_stairs / classroom_2b / xiaomaibu / dorm / cafeteria_steam（共 8 个）。

后续章节（第二至终章）为 post-demo 范围，本文档不展开机制细节，仅列结构性约束。

## 九、关键约束

- **写实**：不超现实，不魔法，不外挂；战斗工具必须是"小学生能拿到的东西"
- **元生 = 镜头**：元生不承担"成长为强者"的弧线主驱动；他的视角承载"那一年发生了什么"
- **友谊线，不是情感线**：v2 已删除暗恋向；保留王炎下行线 + 新增曾建明上行线（一班-二班桥梁）
- **平等的代价**：曾建明是元生第一个平等的同龄朋友，但平等意味着双向脆弱——他也会无心说出"我请你"刺到元生的钱包羞耻度
- **语言**：方言授课语境，对白可带方言色彩，但 UI 文案统一普通话
- **音乐与音效**：本文档不展开，留给后续 audio-direction

## 十、Open Questions（待 GDD / ADR 解决）

1. 俯视近战手感细节（出招帧数、HP / 勇气槽具体上限、闪避无敌帧、4 方向出招判定盒）→ `combat-system.md`
2. 场景切换协议（楼梯口、校门、宿舍等切场点的状态保持与 cutscene 衔接）→ ADR
3. 现有 `base_character_controller.gd`（俯视 4 方向）的能力扩展路径（攻击/受伤/闪避如何叠到现有 walk/idle 状态机上）→ ADR + 系列 stories
4. 后续章节的 post-demo 内容是否进入同一个 build？→ 范围决策
5. 多结局分支收敛点（终章独白如何根据 demo 累积变量分流）→ 总章节 GDD

## 十一、Acceptance Criteria（concept-level）

- [ ] 玩家能在 demo 内完整体验序章 + 第一章
- [ ] 玩家能感受到属性 / 隐性变量 / 好感度对对话与事件的真实影响
- [ ] 战斗节点（曹正东第一次抢钱）能让玩家在 A / B / C 三选项之间真实犹豫
- [ ] 时代切片（开学、神舟七号、三鹿）能在 cutscene / 对白中被自然带出，不强行说教
- [ ] 元生的"镜头感"成立——玩家不会觉得自己在玩一个"成长为强者"的角色
- [ ] 俯视近战手感参考《Hyper Light Drifter》《Death's Door》之类俯视动作 RPG，但战斗节奏远低于纯动作游戏
- [ ] 任何选择都不会显著低于"正确选择"——A（软）路线在叙事价值上等同于 C（硬刚）
