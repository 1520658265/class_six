# 横版格斗 RPG（已废弃方向）

## 现状

- **Status:** Superseded
- **废弃日期:** 2026-06-01
- **取代方向:** 俯视 4 方向（以现有代码为准 — `scripts/character/base_character_controller.gd` 即俯视 4 方向移动控制器）

## 为什么废弃

立项早期评估过两条路线：

1. **横版格斗 RPG** — 即本目录两份 spec 描述的方向，参考《空洞骑士》《铲子骑士》。
2. **俯视 4 方向探索 + 叙事 RPG** — 当前实现选择的方向，更贴近作品的"写实山区童年、叙事驱动"基调。

横版方案与"小学生写实战斗"的合理性框架在物理感受上不太契合（重力/跳跃/帧数判定容易把基调推到动作游戏方向），且代码侧已经按俯视 4 方向落地。两份 spec 在 2026-06-01 决策日被宣告 Superseded。

## 为什么保留而非删除

里面的几块机制设计，移植到俯视战斗依然有参考价值：

- **情绪状态系统**（自卑 / 护短爆发 / 被记住了 / 姐姐在底）— 不依赖横版，直接可用
- **胆量解锁里程碑表**（胆量 1-2 只能忍/逃 → 3 推开 → 4 顶回去 → 5 爆发 → 6+ 反推 BOSS）— 属性驱动，与视角无关
- **道具回忆映射**（铝饭盒/悠悠球/大白兔糖/同学录/姜茶等的功能定义）— 与战斗形式无关
- **章节关卡冲突点设计**（楼梯口抢钱 / 下山路当众发难 / 厕所最终对决 4 结局分支）— 叙事节点和分支结构可保留，仅"战斗呈现方式"需重新定
